1. Four Critical Bottlenecks of Enterprise Financial AI
Part I: Pain Points & Challenges
1. Hallucination & Drift

Without formal domain ontology constraints, pure prompting causes LLMs to fabricate financial metrics, support/resistance levels, and causal supply-chain links.

2. Token Bloat & Latency

Feeding all user holdings (20+ tickers) into a single prompt consumes 30k+ tokens, causing 12s+ TTFT latency and runaway compute costs.

3. Multi-Tenant Leakage

Without database security rules and one-way token masking, private portfolios, webhooks, and chat histories risk cross-tenant leakage.

4. Look-Ahead Bias & Rumors

Look-ahead bias in backtests or mixing unverified Reddit/X chatter with official feeds destroys research rigor and live trading performance.

2. Core Foundation: Three-Layer Financial Domain Ontology
Part II: Financial Domain Ontology
Layer 1: Semantic Graph Ontology

Domain "Nouns & Verbs" (neo4j_service.py)

  • 5 Formal Entity Classes: :Stock, :ResearchReport, :InvestmentRationale, :RiskFactor, :MarketCatalyst.
  • 9 Directed Predicates: [:SUPPLIES_TO], [:CUSTOMER_OF], [:COMPETES_WITH], [:PARTNER_WITH], [:BELONGS_TO], enabling 1-to-3 hop Cypher causal graph traversal.
Layer 2: Contract & Lexicon Ontology

Domain "Grammar & Dictionary" (models.py & TermTooltip.jsx)

  • Pydantic Schema Ontology: StockAnalysisContract & MarketBriefingContract enforce explicit support/resistance levels and trigger Reflection retries on violation.
  • Bilingual Cognitive Lexicon (FINANCIAL_GLOSSARY): Standardizes 40+ concepts across 5 domains into {summary, practical, formula, category} via React Portal tooltips.
Layer 3: Kinetic & Action Ontology

Domain "Decisions & Self-Healing" (Kinetic Operators)

  • 9:30 AM Pre-Market Operators: Maps |Gap| ≥ 2% & RVOL ≥ 1.5x into SHORT_SQUEEZE / GAP_AND_GO playbooks across 3 risk profiles.
  • 27-Sector RRG & Strategy Operators: Maps RS-Ratio & RS-Momentum into quadrant transitions, 60/40 drift alerts, and T+5 parameter self-healing.

6. Neo4j GraphRAG & 5-Tier Heterogeneous Storage (1,500+ Vault)
Part IV: GraphRAG & 5-Tier Storage
🌐 Neo4j 2-Hop Supply Chain Graph & Mandatory OHLCV
  • Multi-Hop Topology Extraction: Neo4jGraphService executes Cypher queries for 1-3 hop supply chain relations (e.g., TSMC -[:SUPPLIES_TO]-> NVDA -[:CUSTOMER_OF]-> MSFT).
  • Mandatory OHLCV Dashboard: Chatbot is forced to output Open, High, Low, Close, % Change, Volume, 10d Avg Vol, VWAP, RSI(14), SMA(20/50) before narrative text.
  • Strict Fact Grounding: Missing metrics are stated as "No official data disclosed" rather than fabricated.
🗄️ 5-Tier Storage Topology & 1,500+ Research Vault
  • L1 In-Memory TTL Cache: 60s TTL for quotes, 15m TTL for FRED macro series, preventing upstream rate-limit cascades.
  • L2 Firestore + L3 Neo4j AuraDB + L4 GCS Multimodal CDN: Powers multi-tenant state, graph topology, and 24fps video briefings.
  • L5 GCP Research Vault (Firebase Cloud Archive): SQLite + FTS full-text index hosting 1,500+ long-form bilingual institutional equity research reports.

8. Multi-Tenant RBAC & Zero-Trust Data Privacy Isolation
Part VI: Multi-Tenant & Security
🛡️ Cryptographic Firestore Isolation (firestore.rules)
  • Strict Rule Enforcement: Direct client SDK access is restricted to request.auth.uid == userId.
  • No Client User ID Parameter: Backend extracts uid strictly from Google-signed JWT Bearer tokens; arbitrary user_id parameters are rejected.
  • Zero-Key Cloud-Native Auth: Built on GCP ADC + IAM roles with SensitiveDataFilter log sanitization.
🔑 Dynamic Webhook Masking & Quota Matrix
  • One-Way Masking: WeChat Work (key=36a2****6987) and Discord (.../f0C3****q6tk) secrets are masked in API responses.
  • Non-Destructive Updates: Submitting masked strings containing **** preserves existing stored credentials on the backend.
  • Tier Matrix Quotas: Free (1 holding), Trial (5 holdings, 2 observe), Paid/Pro (15 holdings, 5 observe, 15-day grace period), Super/Admin (unlimited).

10. Seven-Fold Autonomous Self-Healing SRE Closed Loops (MAPE-K)
Part VII: Loop Architecture
🤖 1. AI Format Self-Audit Loop

Pydantic ontology contracts intercept Gemini output; validation failures assemble Reflection Error Prompts for re-reasoning (up to 3 retries).

⚡ 2. API State Machine Circuit Breaker

FMP failures trip breaker (CLOSED ➔ OPEN), triggering seamless fallback to yfinance or multi-tier Firestore cache.

🔍 3. Cache Miss Self-Fill Loop

Cloud Scheduler scans Firestore missing cache and executes Prewarm prior to weekly report dispatch.

📊 4. Gems Win Rate Evolution Loop

Scans past 30-day stock signals vs T+5 actual prices, calculating profit factor and tuning strategy_params thresholds.

🚨 5. Unhandled SRE Feedback Loop

FastAPI error interception connects to GCP Error Reporting and dispatches Discord alerts with code fix suggestions.

🛡️ 6. Runaway Sanitizer & Canary Loop

Eliminates degenerate table delimiter loops, enforces 5-chunk caps (0.35s pacing), and pairs with Cloud Run 10% Canary auto-rollback.

📝 7. Ontology & Documentation Sync Loop (Doc-Sync Loop)

Keeps the Three-Layer Financial Domain Ontology, Algorithm Whitepaper, System Architecture, and Bilingual User Manuals 100% synchronized with production schemas.
