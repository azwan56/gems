1. 系统整体数据库架构与协同关系

系统采用 NoSQL 文档数据库 + 关系图数据库 + 对象存储 + 内存级熔断缓存的异构多模态架构，实现高性能与高可用性。

存储组件 数据库类型 核心职责与保存的内容
Google Cloud Firestore NoSQL 文档数据库 (主业务库) • 用户与权限：用户 Profile (`users/`)、身份鉴权、订阅等级。
• 研报与历史归档：每日盘前简报 (`reports/`)、每周审计周报 (`weekly_cache/`)、宏观分析 (`macro_cache/`)、财报拆解 (`earnings_reports/`)。
• 策略与快照：Gems 策略快照 (`gems_rebalance_snapshots/`)、自选股列表 (`stock_pool`)。
• 系统配置：龙头股权重表、SRE 健康探针状态 (`system_status`)。
Neo4j (AuraDB) 图数据库 (Graph RAG) • 产业链与上下游拓扑：如 AAPL → TSM（代工关系）、NVDA → TSMC → ASML。
• 多跳关联图谱 (Multi-Hop Topologies)：板块传导效应、竞争对手替代关系、因果传导路径。
• AI 研报上下文增强：为 Gemini 生成深度研报提供图谱拓扑信息。
Firebase Storage 对象存储 (Object Storage) • 媒体与渲染产物：生成的微信公众号预览页 HTML、动态渲染的 PNG K线与研报分享卡片。
内存/本地缓存 In-Memory Cache • 高频行情缓存：FMP API 价格、VWAP、SMA 缓存。
• Circuit Breaker 熔断降级：外部 API 故障时的自动降级保护。

2. Neo4j 图数据库四大类关键关系模型

打破传统孤立看盘，在图数据库中构建产业链、竞品对标、生态联盟及研报质性逻辑四大拓扑关系。

1. 上下游供应链关系 (SUPPLIES_TO)

记录芯片晶圆代工、组装厂及核心零部件供应商拓扑。如 AAPL → Foxconn、NVDA → TSM。当代工厂产能受限时，自动推导下游供给风险。

2. 行业竞品对标关系 (COMPETES_WITH)

记录同赛道竞争对手关系（如 NVDA vs AMD、MSFT vs GOOGL）。当某龙头财报异动时，实时推导对竞品估值与市场份额的连带影响。

3. 战略合作伙伴关系 (PARTNER_WITH)

记录非买卖关系的资本与生态联盟（如 MSFT -[PARTNER_WITH]-> OpenAI）。捕捉非传统交易下的深层生态捆绑效应。

4. 研报质性逻辑与事件图谱 (Knowledge Graph)

将研报拆解为节点关系：包含分析师研报概览 (:ResearchReport)、核心投资逻辑 (:InvestmentRationale)、风险因子 (:RiskFactor) 与股价催化剂 (:MarketCatalyst)。

3. 量化选股与操盘 5 大维度核心数据与业务逻辑

基于宏观、定量基本面、技术动量、财报预期差及动态再平衡构筑 5 重筛选防火墙。

① 宏观经济与流动性

对接 FRED API，监控美联储利率 (FFR)、CPI/PCE 通胀、NFP 非农及美债 10Y-2Y 倒挂。倒挂期自动调紧防御风控，降息预告期提高成长股权重。

② 定量基本面评分

基于 Profitability (30%) + Growth (40%) + Safety & Cash Flow (30%) 计算 0-100 的 Fundamental Score。强约束 ROE > 20%、PEG < 1.0。

③ 技术面与动量量化

计算 Technical Score：结合 50SMA/200SMA 多头排列、52 周高点偏离度 (Proximity to 52w High)、RSI (14) 与 MACD 金叉，防止触底接刀。

④ 财报预期差与资金面

监控财报超预期幅度 (Earnings Surprise % > 15%)，结合华尔街分析师目标价上修空间 (Analyst Target Upside) 捕捉爆发标的。

⑤ 战术再平衡与闭环评估

基于标的 Beta、波动率及策略权重，计算持仓再平衡优化比例，由后置评估引擎实盘校验。

4. 闭环胜率评估算法与 AI 自愈进化机制

以后置实盘收益表现为标准，驱动策略门槛参数自动化进化。

评估指标计算公式：
• T+5 / T+20 胜率 = (成功单数量 / 总推荐标的数量) × 100%
• 盈利单平均收益 = ∑(所有盈利单收益率) / 盈利单总数量
• 单均期望收益 = (胜率 × 盈利单平均收益) - (败率 × 亏损单平均亏损)

当前实盘表现：T+20 胜率 71.4%，盈利单平均收益 +8.4%，数学期望收益率高达 +4.86% (盈亏比 2:1 以上)。
