1. 核心架构哲学：三层金融领域本体论 (Financial Domain Ontology)

传统 AI 投研直接将零散行情 JSON 与新闻抛给大模型，极易产生金融幻觉。本系统借鉴 Palantir Foundry / AIP 本体论（Ontology）工程思想，在原始数据层与 Gemini 推理层之间构建了包含“语义实体、形式化契约、可执行决策算子”的三层金融领域本体。

第一层：语义实体与图谱本体
Semantic Entity & Graph Ontology

在 Neo4jGraphService 中形式化定义美股领域的“名词（Entity Classes）”与“动词（Object Properties）”：

  • 5 大核心本体类：上市公司 :Stock、结构化研报 :ResearchReport、多空论据 :InvestmentRationale、风险因子 :RiskFactor、催化剂 :MarketCatalyst。
  • 4 类有向语义关系：供应链上下游 SUPPLIES_TO / CUSTOMER_OF、同赛道竞品 COMPETES_WITH、战略生态联盟 PARTNER_WITH、研报逻辑挂载 HAS_RATIONALE / RISK / CATALYST。
第二层：形式化契约与认知本体
Contract & Cognitive Lexicon Ontology

消除自由文本歧义，建立机器推理与投资者认知的“单一事实来源（Single Source of Truth）”：

  • Pydantic 强类型契约本体：StockAnalysisContract 与 MarketBriefingContract 强制绑定多空极性、量化支撑位 key_supports、阻力位 key_resistances，未通过校验自动触发 Reflection 自审重试。
  • 双语金融术语本体库：TermTooltip 将 40+ 核心概念按技术面、基本面、宏观、量化回测、选股策略 5 大本体域标准化为“概念定义 + 实战操盘含义 + 数学公式”。
第三层：动力学与行动本体
Kinetic & Action Ontology

本体不仅描述“市场是什么”，更定义“特定状态下执行什么战术算子”：

  • 盘前 9:30 AM 攻防战术算子：将跳空缺口、WSB 情绪与做空比映射为 SHORT_SQUEEZE / GAP_AND_GO 态势，按保守/稳健/激进三档风险偏好输出开盘指令。
  • RRG 四象限轮动算子：依据 27 大行业 ETF 在 Leading / Improving / Weakening / Lagging 象限的动量轨迹自动生成调仓信号。
  • 胜率衰减自愈算子：当实盘胜率低于 50% 时自动上调 ROE 门槛并收紧负债率约束。

2. 五维异构多模态数据库架构与协同关系

系统采用 NoSQL 文档主库 + Neo4j 图谱本体库 + 阿里云 1500+ 私有投研库 + 对象存储 + 状态机熔断缓存的五维异构架构。

存储组件 数据库类型 核心职责与保存的内容
Google Cloud Firestore NoSQL 文档数据库 (主业务库) • 用户与权限：用户 Profile (users/)、零信任鉴权、订阅等级与多端推送配置。
• 研报与历史归档：每日持仓与观察池简报 (reports/)、每周审计周报 (weekly_cache/)、宏观分析 (macro_cache/)、财报 NLP 拆解 (earnings_archive/)。
• 策略与快照：Gems 策略快照 (gems_rebalance_snapshots/)、SRE 健康探针状态 (system_status)。
Neo4j (AuraDB) 图数据库 (GraphRAG 本体引擎) • 产业链上下游本体拓扑：如 AAPL → TSM → ASML、NVDA → TSMC → ASML。
• 多跳关联图谱 (1~3 Hops)：板块传导效应、竞争对手替代关系、战略合作联盟。
• 研报认知图谱：将定性研报映射为 :ResearchReport、:InvestmentRationale、:RiskFactor、:MarketCatalyst 节点。
阿里云私有投研库 (Aliyun Vault) 云端私有研报归档库 • 1500+ 篇深度美股机构研报：支持按代码、关键词、行业分类高速检索、移动端沉浸式阅读及微信公众号排版导出。
Firebase Storage 对象存储 (Object Storage) • 多模态媒体产物：Canvas 2.0 高清 K 线分享长图 PNG、6-Slide 财报 PPT 海报、微信公众号 HTML 预览页。
内存/本地熔断缓存 In-Memory Stateful Cache • 高频行情与问答热缓存：FMP 实时价格、VWAP、SMA 缓存及 UnifiedQAEngine 5 分钟线程安全热缓存。
• Circuit Breaker 熔断降级：外部 API 连续故障时的秒级无感切换保护。

3. Neo4j 领域知识图谱本体四大关系模型

打破传统孤立看盘，在图数据库中构建产业链、竞品对标、生态联盟及研报质性逻辑四大本体关系。

1. 上下游供应链关系 (SUPPLIES_TO / CUSTOMER_OF)

记录芯片晶圆代工、光刻设备、组装厂及云厂商算力采购拓扑。如 AAPL → Foxconn、NVDA → TSM → ASML。当上游产能或资本开支受限时，自动通过多跳遍历推导下游供给风险。

2. 行业竞品对标关系 (COMPETES_WITH)

记录同赛道竞争对手关系（如 NVDA vs AMD、MSFT vs GOOGL）。当某龙头财报异动时，实时推导对竞品估值与市场份额的连带溢出影响。

3. 战略合作伙伴关系 (PARTNER_WITH)

记录非买卖关系的资本与 AI 生态联盟（如 MSFT -[PARTNER_WITH]-> OpenAI）。捕捉非传统交易下的深层生态捆绑效应。

4. 研报质性逻辑与事件图谱 (Knowledge Graph)

将研报拆解为形式化本体节点：包含研报概览 (:ResearchReport)、核心投资逻辑 (:InvestmentRationale)、风险因子 (:RiskFactor) 与股价催化剂 (:MarketCatalyst)。

4. 量化选股、27 维 RRG 轮动与实盘操盘 6 大核心维度

基于宏观两阶段反应、27 维 RRG 行业轮动、定量基本面、技术动量、财报 NLP 语调及 60/40 动态再平衡构筑 6 重防火墙。

① 宏观流动性与 P1/P2 二阶段反应

对接 FRED API，监控美联储利率、CPI/PCE、非农及美债 10Y-2Y 利差。重磅数据发布后 0.5h 自动生成 P1 快报，4.0h 生成 P2 二阶段机构消化定调报告，过滤盘初假突破噪音。

② 27 维 RRG 全行业相对轮动图谱

追踪 11 大标普 GICS 一级行业 ETF + 16 大高 Alpha 主题 ETF（半导体 SMH、AI BOTZ、网安 CIBR、核能 URA 等）在领涨、转强、转弱、落后四象限的 5 周轮动轨迹。

③ 定量基本面评分 (0-100)

基于 Profitability (30%: ROE + 毛利率) + Growth (40%: 营收 + EPS 增速) + Safety & Cash Flow (30%: FCF Yield + 流动比率) 计算严谨的 Fundamental Score。

④ 技术动量与盘前 9:30 攻防剧本

结合 50SMA/200SMA 偏离度与 52 周高点位置计算 Technical Score（跌破 200SMA 超 20% 触发 Minervini 红线归零）；盘前融合 Gap%、WSB 热度与做空比生成三档开盘战术。

⑤ 财报预期差与高管 NLP 语调拆解

监控财报实际 EPS/营收超预期幅度 (Surprise %)，并对高管电话会纪要进行 NLP 情绪极性、指引置信度分析，自动渲染 6-Slide PPT 海报。

⑥ 60/40 股债漂移与情景压力测试

在月末/季末 T-5 与 T-2 监控 SPY vs BND 收益差（超 ±3.0% 预警机构再平衡），并支持科技估值修正、鹰派加息、通胀飙升、地缘升级 4 大宏观情景压力测试。

5. 机构级步进回测实验室 (Walk-Forward Backtest Lab)

彻底摒弃带有“前视偏差”的简易回测，引入真实交易摩擦成本、Lo (2002) 自相关修正夏普比率与 52 周个股信号重演。

🧪 组合级四大策略与统计显著性检验

6. 闭环胜率评估算法与七重自主自愈机制 (Autonomous SRE Loops)

以实盘 T+5 / T+20 收益表现为标准驱动策略参数进化，配合七重 SRE 闭环实现 99.9% 无人值守运行。

核心胜率与数学期望公式 (System Expectancy)：
• T+5 / T+20 胜率 = (成功单数量 / 总推荐标的数量) × 100%
• 单均期望收益 (Expectancy) = (胜率 × 盈利单平均收益) - (败率 × 亏损单平均亏损)

实盘基准表现：T+20 胜率 71.4%，盈利单平均收益 +8.4%，数学期望收益率达 +4.86% (盈亏比 > 2:1)。
